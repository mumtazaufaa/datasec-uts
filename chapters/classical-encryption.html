PRIORITAS LATIHAN HITUNG

Classical Encryption

Materi ini mendapat prioritas belajar tertinggi menurut kisi-kisi UTS: pahami algoritma, tulis langkah, lalu latih enkripsi dan dekripsi tanpa melihat kunci jawaban.

Model cipher simetris

Plaintext + secret key → encryption algorithm → ciphertext. Dekripsi menggunakan ciphertext dan key untuk memperoleh plaintext asli.

Cara mengerjakan soal

  1. Identifikasi algoritma yang diminta dan bentuk key-nya.
  2. Tulis aturan atau rumus sebelum mengganti huruf.
  3. Untuk algoritma berbasis alfabet, tentukan pemetaan angka huruf terlebih dahulu jika metode dosen menggunakan A=0, B=1, …, Z=25.
  4. Kerjakan semua langkah dan pertahankan urutan pasangan huruf/vektor.
  5. Untuk dekripsi, balikkan aturan enkripsi secara benar. Jangan sekadar menebak plaintext.
  6. Periksa kembali hasil dengan mengenkripsi plaintext hasil dekripsi jika memungkinkan.

1. Caesar Cipher

Caesar Cipher mengganti setiap huruf dengan huruf yang berjarak tetap dalam alfabet. Dengan pemetaan A=0 sampai Z=25 dan shift k:

Encryption: C = (P + k) mod 26
Decryption: P = (C − k) mod 26

Contoh enkripsi

Plaintext CAT, shift k = 3.

HurufNilai PPerhitunganHuruf C
C2(2 + 3) mod 26 = 5F
A0(0 + 3) mod 26 = 3D
T19(19 + 3) mod 26 = 22W

Hasil ciphertext: FDW. Untuk dekripsi, kurangi shift dari setiap nilai ciphertext dan gunakan modulo 26 jika hasilnya negatif.

2. Monoalphabetic substitution

Setiap huruf plaintext dipetakan ke satu huruf ciphertext berdasarkan satu substitusi tetap. Slide menjelaskan bahwa permutasi 26 huruf menghasilkan 26! kemungkinan susunan key. Kelemahan praktis yang dibahas adalah analisis frekuensi huruf, digram (pasangan huruf), dan trigram (tiga huruf), misalnya frekuensi umum dalam bahasa Inggris.

3. Playfair Cipher

Playfair mengenkripsi dua huruf sekaligus (digraph) menggunakan matriks 5×5. Contoh di slide menggunakan keyword MONARCHY; huruf I dan J digabung dalam satu sel.

  1. Buat matriks dari keyword dengan menghapus huruf duplikat.
  2. Isi sisa matriks dengan huruf alfabet yang belum dipakai, biasanya tanpa J.
  3. Bagi plaintext menjadi pasangan. Jika sepasang huruf berulang, sisipkan filler seperti X; contoh slide: BALLOON → BA LX LO ON.
  4. Satu baris: geser masing-masing huruf ke kanan, dengan wrap-around.
  5. Satu kolom: geser masing-masing huruf ke bawah, dengan wrap-around.
  6. Persegi panjang: masing-masing huruf diganti dengan huruf di barisnya sendiri dan kolom huruf pasangannya.

Dekripsi: aturan baris dan kolom dibalik arah (kiri/atas); aturan persegi panjang tetap menggunakan sudut yang berlawanan sesuai aturan pasangan.

4. Hill Cipher

Hill Cipher menggunakan aljabar linear: blok huruf dipetakan ke vektor angka dan dikalikan dengan matriks key, lalu hasilnya direduksi modulo 26. Materi Session 3–4 mencantumkan Hill Cipher, tetapi detail contoh matriks harus mengikuti notasi pada slide/dosen.

Enkripsi: C = K · P (mod 26)
Dekripsi: P = K⁻¹ · C (mod 26)

Untuk dekripsi, matriks key harus memiliki invers modulo 26. Syaratnya gcd(det(K), 26) = 1. Jika tidak, key tidak dapat dibalik secara valid untuk dekripsi Hill Cipher.

Langkah umum dekripsi Hill

  1. Hitung determinan matriks key.
  2. Temukan invers perkalian determinan modulo 26.
  3. Hitung adjugate (transpose matriks kofaktor).
  4. Kalikan adjugate dengan invers determinan dan reduksi semua elemen modulo 26 untuk memperoleh K⁻¹.
  5. Kalikan K⁻¹ dengan vektor ciphertext dan reduksi modulo 26.
  6. Ubah angka hasil kembali menjadi huruf dengan pemetaan yang digunakan dosen.

5. Vigenère Cipher

Vigenère adalah polyalphabetic substitution: beberapa aturan substitusi seperti Caesar digunakan bergantian berdasarkan key. Key diulang sampai sepanjang plaintext.

Encryption: Cᵢ = (Pᵢ + Kᵢ) mod 26
Decryption: Pᵢ = (Cᵢ − Kᵢ) mod 26

Dengan A=0, B=1, …, Z=25. Pastikan key disejajarkan dengan plaintext dan diulang sesuai panjang pesan.

6. Transposition techniques

Berbeda dari substitution yang mengganti simbol, transposition mengubah posisi huruf plaintext. Slide mencakup Rail Fence dan penulisan ke dalam persegi panjang lalu membaca kolom dengan urutan kolom sebagai key.

  • Rail Fence: tulis huruf secara zigzag pada sejumlah rail, kemudian baca per baris.
  • Columnar transposition: tulis plaintext per baris ke dalam grid dan baca kolom sesuai urutan key.

Latihan mandiri

Soal A — Enkripsi Caesar
Enkripsikan DATA dengan shift 4. Tulis nilai angka dan hasil setiap huruf.

Lihat pembahasan

D=3 → (3+4)=7=H; A=0 → 4=E; T=19 → 23=X; A=0 → 4=E. Ciphertext: HEXE.

Soal B — Dekripsi Caesar
Diketahui ciphertext KHOOR dengan shift 3. Temukan plaintext.

Lihat pembahasan

K=10 → 10−3=7=H; H=7 → 4=E; O=14 → 11=L; O=14 → 11=L; R=17 → 14=O. Plaintext: HELLO.

Soal C — Identifikasi algoritma
Jika plaintext diproses dua huruf sekaligus menggunakan matriks 5×5, algoritma apa yang paling mungkin digunakan?

Lihat jawaban

Playfair Cipher. Perhatikan aturan baris, kolom, dan persegi panjang.
